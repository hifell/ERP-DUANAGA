# 1. BRAND OVERVIEW

## 1.1 Brand Positioning

**B-Automate** adalah brand otomatisasi bisnis yang membantu perusahaan mengelola operasional dengan sistem terintegrasi. Fokus utama adalah efisiensi, profesionalisme, dan solusi teknologi yang mudah dipahami.

## 1.2 Tagline

> **"Bisnismu jalan, sistemnya otomatis."**

## 1.3 Brand Personality

| Attribute | Description |
|-----------|-------------|
| **Professional** | Tampilan bersih, terstruktur, business-focused |
| **Modern** | Tech-forward, mengikuti perkembangan teknologi |
| **Accessible** | Solusi yang bisa dipahami non-technical user |
| **Reliable** | Trusted partner untuk transformation digital |
| **Efficient** | Fokus pada hasil dan penghematan |

## 1.4 Brand Values

```
✓ EFFICIENCY     — Hemat waktu, hemat biaya
✓ AUTOMATION     — Kurangi manual, maksimal teknologi
✓ GROWTH         — Skalabilitas bisnis
✓ SIMPLICITY     — Sistem yang mudah dipahami
✓ RELIABILITY    — Partner jangka panjang
```

```
│                                         │
```

## 2.4 Logo Don'ts

```
✗ Don't stretch or distort the logo
✗ Don't change the logo colors
✗ Don't add shadows or effects
✗ Don't place on busy backgrounds without contrast
✗ Don't use low-resolution versions
✗ Don't recreate the logo from scratch
```

```
FONT: Inter
```

**Mood:** Professional, tech-forward, approachable

**Subjects:**
- People working with technology (diverse, modern)
- Clean office environments
- Abstract tech visualizations
- Workflow/process diagrams

**Treatment:**
- Slight cool tint matching brand colors
- Natural lighting preferred

# 8. VOICE & TONE

## 8.1 Voice Attributes

| Attribute | Definition | Example |
|-----------|------------|---------|
| **Professional** | Business-appropriate, expert | "Solusi ERP terintegrasi" |
| **Clear** | Easy to understand, no jargon | "Hemat 40% waktu" |
| **Confident** | Assured, knowledgeable | "Sistem yang proven" |
| **Helpful** | Solution-oriented | "Membantu bisnis Anda tumbuh" |
| **Modern** | Tech-forward, contemporary | "Otomatisasi, bukan manual" |

## 8.2 Tone Guidelines

| Situation | Tone | Example |
|-----------|------|---------|
| **Marketing** | Confident, benefit-focused | "Hemat waktu, naikkan revenue" |
| **Technical** | Precise, clear | "API endpoint: /webhook/lead" |
| **Support** | Helpful, patient | "Kami bantu sampai sistem jalan" |
| **Casual** | Friendly, approachable | "Jadi lebih gampang deh" |

## 8.3 Writing Guidelines

### Do:
```
✓ Use active voice
✓ Keep sentences short (15-20 words)
✓ Focus on benefits, not features
✓ Use numbers: "40%" not "forty percent"
✓ Include action verbs
```

### Don't:
```
✗ Use excessive technical jargon
✗ Write paragraphs instead of bullet points
✗ Use passive voice unnecessarily
✗ Overuse exclamation marks
✗ Use informal slang in formal contexts
```

## 8.4 Sample Copy

### Headline Formats
```
┌─────────────────────────────────────────────────────────────┐
│  FORMAT: [Action] + [Benefit]                            │
│                                                             │
│  ✓ "Otomatisasi. Optimalisasi. Perluas Bisnis."           │
│  ✓ "Hemat 40% waktu kerja dengan sistem terintegrasi"      │
│  ✓ "Bisnismu jalan, sistemnya otomatis."                 │
│                                                             │
│  AVOID: "We provide comprehensive ERP solutions..."        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### Body Copy Examples
```
GOOD:
"Biarkan teknologi yang menangani pekerjaan repetitif, 
sementara Anda fokus menumbuhkan bisnis."

BAD:
"Perusahaan kami menyediakan layanan otomatisasi 
bisnis yang komprehensif untuk enterprise solution."
```

# 11. DO'S AND DON'TS

## 11.1 Logo Usage

```
✓ DO                                                     ✗ DON'T
───────────────────────────────────────────────────────
Use the official logo file                    Use screenshots or recreations
Maintain clear space around logo             Crowd the logo with other elements
Use approved color variants                  Change logo colors
Use high-resolution versions               Use blurry or pixelated logos
```

## 11.2 Color Usage

```
✓ DO                                                     ✗ DON'T
───────────────────────────────────────────────────────
Use brand colors for all materials           Use off-brand colors randomly
Maintain proper contrast ratios              Use low contrast combinations
Use Navy/Blue as primary colors             Use brand colors for decoration only
```

## 11.3 Typography

```
✓ DO                                                     ✗ DON'T
───────────────────────────────────────────────────────
Use Google Fonts (Space Grotesk, Inter,      Use system defaults (Arial, Times)
JetBrains Mono)
Use proper font hierarchy                   Mix too many font weights
Keep text readable at all sizes             Use text below 12px for important info
```

## 11.4 Imagery

```
✓ DO                                                     ✗ DON'T
───────────────────────────────────────────────────────
Use professional, relevant photos           Use low-quality or stock clichés
Maintain consistent visual style             Use mismatched photography styles
Include brand colors subtly                  Use irrelevant or distracting images
```
