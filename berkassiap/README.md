# BERKAS SIAP - PT DUA NAGA KOSMETINDO
## ERP Implementation Package

### Folder Structure:

```
berkassiap/
├── proposal/              → Dokumen proposal lengkap (PDF-ready)
├── dokumentasi/           → Panduan penggunaan ERP
├── n8n_workflows/        → Automation workflows JSON
├── software/              → Installer & setup scripts
└── training/              → Video tutorial & SOP
```

### Quick Start:

1. Baca PROPOSAL di folder proposal/
2. Setup software dengan docker-compose.yml
3. Import n8n workflows dari folder n8n_workflows/
4. Gunakan dokumentasi untuk panduan
